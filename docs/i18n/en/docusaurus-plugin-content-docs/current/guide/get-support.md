magWin support is provided **by email**. There is no phone support, and replies go out in the order received. Checking the steps below first solves most problems right away.

## 1. Look for an answer in Help

- App: menu bar icon › **magWin Help…**. Search, or expand the frequently asked questions.
- Web: browse by topic in the [Help Center](/help).
- Fixes by symptom are collected in [Troubleshooting](troubleshooting.md).

## 2. Check permissions and status

Open menu bar icon › **Permissions & Status…** and check the following.

| Item                        | Healthy state                                              |
| --------------------------- | ---------------------------------------------------------- |
| Native helper               | Running                                                    |
| Accessibility               | Allowed                                                    |
| Desktop switch shortcut     | Available ("Switch to Desktop N" or move left/right is on) |
| Screen Recording (optional) | Fine to be off                                             |

## 3. Contact us

Open menu bar icon › **Get Support…**.

1. Click **Copy diagnostics** to copy the app version, macOS version, helper status, permissions, and shortcut status.
2. Click **Email support** to open a draft email with the diagnostics included.
3. Describe what you were doing and what happened, then send it.

:::info What diagnostics do not include
Window titles, app names, and layout names are not included in diagnostics. Add them yourself if needed.
:::

## When you contact us

- Include any error message or screenshot, and **when the problem first started**.
- Describe the steps that make the problem happen again. Steps to reproduce make it much faster to resolve.
- Rather than sending a new message about the same problem, **reply to the email you received**. Keeping one conversation keeps everything in one place.
- If a colleague is looking at it with you, add them as CC when you reply.
