## 사용법

1. 옮기고 싶은 창의 **가장자리**(위·아래·왼쪽·오른쪽)에 커서를 올리고 잠깐(기본 0.35초) 멈춥니다.
2. 커서 위치에 **그리드 팔레트**가 뜹니다. 설정한 그리드 프리셋(기본 2×2, 2×3, 3×2, 3×3, **사용자 정의**)이 나란히 놓입니다. 각 그리드 위에는 **왼쪽에 이름**(예: `3 × 2`)이 있습니다.
3. 한 그리드에서 칸을 고릅니다. 클릭하면 한 칸, **누른 채 끌면** 지나간 칸을 감싸는 직사각형이 선택됩니다.
4. 선택하는 순간 그 그리드 이름의 **오른쪽**에 **적용** 버튼이 나타납니다(팔레트 방향과 관계없이 같은 자리).
5. **적용**(또는 Enter)을 누르면 창이 그 영역으로 이동하고 크기가 바뀝니다.

선택하는 동안 실제 화면에 반투명 미리보기가 표시되고, 적용 버튼에 마우스를 올리면 결과 크기(예: `756 × 713`)가 보입니다.

> 표기는 **가로 칸 × 세로 칸**입니다. `3x2`는 가로 3칸, 세로 2줄입니다.

## 사용자 정의 그리드

마지막 그리드는 팔레트에서 바로 모양을 바꿀 수 있습니다. 처음에는 2 × 2이고, 그리드 상·하·좌·우 바깥에 바깥을 향한 삼각형 화살표가 있습니다.

| 화살표   | 동작                  |
| -------- | --------------------- |
| ▶ 오른쪽 | 열(가로 칸) 하나 추가 |
| ◀ 왼쪽   | 열 하나 줄이기        |
| ▼ 아래   | 행(세로 줄) 하나 추가 |
| ▲ 위     | 행 하나 줄이기        |

- 가로·세로는 1~8칸이며, 끝에 닿은 화살표는 흐리게 꺼집니다.
- 모양을 바꾸면 그 그리드의 선택은 해제됩니다.
- **마지막으로 바꾼 모양은 저장**되어 다음에 팔레트가 뜰 때도, 앱을 다시 실행해도 그대로입니다.
- 관리 창에서 삭제할 수 있고, 삭제한 뒤에는 **사용자 정의 그리드 추가**로 다시 넣을 수 있습니다.

## 선택 규칙

| 동작                          | 결과                                                           |
| ----------------------------- | -------------------------------------------------------------- |
| 칸 클릭                       | 그 칸 하나 선택                                                |
| 칸을 누른 채 다른 칸으로 끌기 | 시작 칸과 현재 칸을 꼭짓점으로 하는 직사각형 (되돌리면 줄어듦) |
| 같은 그리드의 다른 칸 클릭    | 그 칸 하나로 새로 선택                                         |
| ⇧ Shift + 클릭                | 처음 누른 칸부터 클릭한 칸까지 직사각형으로 확장               |
| 선택된 **한 칸**을 다시 클릭  | 선택 해제 → 적용 버튼도 사라짐                                 |
| **다른 그리드**의 칸 누르기   | 이전 그리드의 선택은 사라지고 새 그리드에서 선택               |
| Esc                           | 선택 해제, 선택이 없으면 팔레트 닫기                           |

선택은 항상 한 그리드 안에서만, 항상 직사각형입니다. 자세한 모델은 [그리드 선택 모델](../architecture/grid-selection.md)에 있습니다.

## 팔레트가 닫히는 때

- 커서가 팔레트와 트리거 지점 주변을 벗어난 뒤 **닫힘 지연**(기본 0.45초)이 지났을 때. 드래그 중에는 닫히지 않습니다.
- 적용이 성공했을 때
- Esc를 두 번 눌렀을 때

## 설정 (관리 창 › 설정)

관리 창은 너비가 고정되어 있고 세로로만 늘리고 줄일 수 있습니다. 내용은 창 가운데에 정렬됩니다.

설정 탭은 왼쪽 사이드바에 **팔레트 그리드 · 가장자리 감지 · 팔레트와 배치 · 레이아웃 · 일반** 섹션이 있고, 고른 섹션의 내용이 오른쪽에 나타납니다. 언어와 로그인 시 자동 실행은 **일반**에 있습니다([언어](getting-started.md#언어)).

| 설정            | 기본값                           | 설명                                             |
| --------------- | -------------------------------- | ------------------------------------------------ |
| 팔레트 그리드   | 2×2 2×3 3×2 3×3 사용자 정의(2×2) | 추가(가로·세로 1~8), 삭제, 순서 변경. 최대 12개  |
| 감지할 가장자리 | 네 변 모두                       | 변별로 켜고 끄기                                 |
| 머무름 시간     | 350ms                            | 가장자리 위에서 이만큼 멈춰야 팔레트가 뜸        |
| 감지 폭         | 5px                              | 가장자리 선 양쪽으로 이 거리까지 인식            |
| 함께 누를 키    | 없음                             | ⌥/⌃/⌘/⇧ 중 하나를 누른 채일 때만 뜨게 할 수 있음 |
| 그리드 크기     | 104px                            | 팔레트 안 그리드 한 개의 폭                      |
| 닫힘 지연       | 450ms                            |                                                  |
| 창 간격         | 0px                              | 창과 창, 창과 화면 가장자리 사이 여백            |

## 오작동을 막는 장치

창 가장자리는 macOS의 **크기 조절 핸들**과 같은 자리입니다. 그래서 다음처럼 동작합니다.

- 머무름 시간이 지나야 뜹니다. 지나가는 커서에는 반응하지 않습니다.
- 마우스 버튼이 눌린 동안(창 이동·크기 조절)에는 뜨지 않습니다. 끌기를 끝낸 자리가 가장자리여도, 커서가 한 번 벗어났다 돌아와야 다시 뜹니다.
- 모서리(대각선 크기 조절)에서는 뜨지 않습니다.
- 메뉴 막대와 Dock 영역에서는 뜨지 않습니다.

## 대상이 아닌 창

- 전체 화면 창, 크기나 위치를 바꿀 수 없는 창
- 메뉴 막대 앱처럼 Dock에 없는 앱의 창
- OrgaWin 자신의 창

앱이 최소 크기를 정해 두었다면 창이 선택 영역보다 클 수 있습니다(예: 글자 단위로 크기가 바뀌는 Terminal).
