magWin 지원은 **이메일로** 받습니다. 전화 지원은 없고, 받은 순서대로 답장합니다. 문의하기 전에 아래 순서대로 확인하면 대부분 바로 해결됩니다.

## 1. 도움말에서 답 찾기

- 앱: 메뉴 막대 아이콘 › **magWin 도움말…** 에서 검색하거나 자주 묻는 질문을 펼쳐 보세요.
- 웹: [도움말 센터](/help)에서 주제별로 둘러볼 수 있습니다.
- 증상별 해결 방법은 [문제 해결](troubleshooting.md)에 모여 있습니다.

## 2. 권한과 상태 확인

메뉴 막대 아이콘 › **권한 및 상태…** 에서 다음을 확인하세요.

| 항목                | 정상 상태                                              |
| ------------------- | ------------------------------------------------------ |
| 네이티브 도우미     | 실행 중                                                |
| 손쉬운 사용         | 허용됨                                                 |
| Desktop 전환 단축키 | 사용 가능 ("Desktop N으로 전환" 또는 좌우 이동이 켜짐) |
| 화면 기록 (선택)    | 꺼져 있어도 됨                                         |

## 3. 문의하기

메뉴 막대 아이콘 › **지원 받기…** 를 엽니다.

1. **진단 정보 복사**로 앱 버전, macOS 버전, 도우미 상태, 권한, 단축키 상태를 복사합니다.
2. **이메일로 문의**를 누르면 진단 정보가 들어간 메일 초안이 열립니다.
3. 무엇을 하다가 어떤 일이 생겼는지 적어서 보냅니다.

:::info 진단 정보에 들어가지 않는 것
창 제목, 앱 이름, 레이아웃 이름은 진단 정보에 들어가지 않습니다. 필요하면 직접 적어 주세요.
:::

## 문의할 때 알아 두세요

- 오류 메시지나 스크린샷, **문제가 처음 생긴 때**를 함께 알려 주세요.
- 어떤 순서로 하면 문제가 다시 생기는지 적어 주세요. 재현 순서가 있으면 훨씬 빨리 해결됩니다.
- 같은 문제로 새 문의를 또 보내기보다 **받은 메일에 답장**해 주세요. 한 대화에서 이어 가야 내용이 흩어지지 않습니다.
- 동료와 함께 보고 있다면 답장할 때 참조(CC)로 넣어 주세요.
