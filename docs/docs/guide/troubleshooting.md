먼저 [진단 모드](getting-started.md#진단)로 권한·단축키·헬퍼 상태를 확인하세요.

## 팔레트가 뜨지 않아요

| 확인할 것                              | 해결                                                   |
| -------------------------------------- | ------------------------------------------------------ |
| 메뉴 막대에 "⚠️ 손쉬운 사용 권한 필요" | 권한 및 상태 탭에서 허용. 개발 모드는 터미널 앱에 허용 |
| 메뉴의 "엣지 스냅 사용" 체크           | 켜기                                                   |
| 감지할 가장자리, 함께 누를 키          | 설정 › 가장자리 감지에서 확인                          |
| 모서리나 메뉴 막대 근처에서 시도       | 가장자리 중간에서 시도                                 |
| 방금 그 가장자리를 끌어 크기를 바꿈    | 커서를 한 번 가장자리 밖으로 뺐다가 다시 올리기        |
| 전체 화면 창, 크기 고정 창             | 대상이 아닙니다                                        |

## 권한을 줬는데도 동작하지 않아요

- **개발 빌드를 다시 만들면** ad-hoc 서명이 바뀌어서 macOS가 예전 허용을 인정하지 않을 수 있습니다. 손쉬운 사용 목록에서 항목을 지웠다가 다시 추가하세요. 패키징할 때는 고정된 서명 인증서를 쓰세요([배포](../development/release.md)).
- 권한을 준 뒤에는 앱을 다시 시작하는 것이 확실합니다.

## Desktop이 전환되지 않아요

- 키보드 설정 › 키보드 단축키 › Mission Control에서 "Desktop N으로 전환" 또는 "왼쪽/오른쪽 Space로 이동"을 켜세요.
- 다른 앱이 같은 단축키를 가로채면 "Desktop N으로 전환"이 실패할 수 있습니다. OrgaWin은 이때 좌우 이동으로 한 칸씩 다시 시도합니다.
- 디스플레이별로 Space가 분리되어 있고 대상 Desktop이 다른 모니터에 있으면, 좌우 이동을 위해 커서가 그 모니터로 잠시 옮겨집니다.

## "네이티브 도우미 오류"

- `Helper binary not found`: `pnpm build:helper`로 헬퍼를 빌드하세요.
- `protocol ... does not match`: 앱과 헬퍼 버전이 다릅니다. 둘 다 다시 빌드하세요.
- 헬퍼가 계속 종료되면 다섯 번 재시작한 뒤 멈춥니다. 콘솔 로그의 `[helper]` 줄을 확인하세요.

## 그래도 해결되지 않으면

[지원 받기](get-support.md)의 순서대로 진단 정보를 복사해 이메일로 문의하세요.
