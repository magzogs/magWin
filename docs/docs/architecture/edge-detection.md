## 판정 (헬퍼 `EdgeDetector`)

입력: 커서 위치, 화면에 있는 **일반 앱 창**(layer 0, Dock 앱, OrgaWin 제외) 목록(앞→뒤 순), 디스플레이의 frame과 visibleFrame, Dock 위치(`com.apple.dock` `orientation`: 아래·왼쪽·오른쪽), 감지 폭 `band`, 켜진 가장자리.

1. 커서가 어느 visibleFrame에도 없으면(메뉴 막대·Dock) 판정하지 않습니다.
2. 창을 **앞에서부터** 보며 `band`만큼 넓힌 사각형에 커서가 든 첫 창을 고릅니다. 앞 창이 뒤 창의 가장자리를 가리면 뒤 창은 후보가 되지 않습니다.
3. 네 변까지의 거리 중 `band` 이내인 가장 가까운 변이 결과입니다.
4. **모서리 제외**: 위/아래 변이면 좌우 끝에서 `max(3·band, 16)`px 안쪽, 왼쪽/오른쪽 변이면 위아래 끝에서 그만큼은 제외합니다(대각선 크기 조절 핸들).
5. **Dock 쪽 변 제외**: 결과 변이 Dock 위치와 같은 쪽이고, 그 창 변과 화면(frame) 가장자리 사이 간격이 `band + 8`px 이하이면 판정하지 않습니다. 자동 숨김 Dock은 그 자리로 올라와 창 변과 겹치므로, 여기서 띄우면 Dock과 팔레트가 함께 올라옵니다. 커서 위치에서 그 화면 가장자리 너머에 다른 디스플레이가 있으면 Dock이 나타나지 않는 안쪽 경계이므로 제외하지 않습니다. 같은 창의 다른 변은 그대로 동작합니다.

창 목록(CGWindowList) 읽기가 가장 비싸서 150ms 동안 캐시하고, 마우스 버튼을 뗄 때(창을 옮겼을 수 있음)와 디스플레이 구성이 바뀔 때 비웁니다. 이때 디스플레이 목록과 Dock 위치도 다시 읽습니다(시스템 설정에서 Dock 위치를 바꾸는 클릭 포함).

## 머무름 상태 머신 (헬퍼 `DwellTracker`)

| 상태              | 의미                                         |
| ----------------- | -------------------------------------------- |
| `idle`            | 대기                                         |
| `pending(hit, t)` | 가장자리에 올라온 시각 `t`부터 세는 중       |
| `fired(hit)`      | 이번 방문에서 이미 팔레트를 띄움             |
| `disarmed(hit?)`  | 그 가장자리를 벗어나기 전까지 다시 뜨지 않음 |

게이트(gate)는 관찰마다 계산합니다.

| 게이트     | 조건                                      | 효과                                                                               |
| ---------- | ----------------------------------------- | ---------------------------------------------------------------------------------- |
| `suppress` | 마우스 버튼 눌림, 또는 팔레트가 열려 있음 | 현재 가장자리를 `disarmed`로. **끌어서 크기를 바꾼 뒤 그 자리에서 뜨는 일을 막음** |
| `hold`     | 설정한 보조 키를 누르지 않음              | `idle`로 돌아가되 비활성화하지 않음(키를 누르면 바로 셈 시작)                      |
| `open`     | 그 외                                     | 같은 대상에 dwell 시간 머물면 **한 번** 발화                                       |

커서가 멈춰 있으면 이벤트가 오지 않으므로, `pending` 동안에는 마감 시각에 한 번 더 판정하도록 타이머를 겁니다. 입력은 `NSEvent` 전역 모니터(마우스 이동·버튼·보조 키)라서 가만히 있을 때는 CPU를 쓰지 않습니다.

발화하면 별도 큐에서 AX로 그 창이 **옮길 수 있고 전체 화면이 아닌지** 확인한 뒤 `edge.hover`를 보냅니다. 권한이 없으면 `edge.blocked`를 보냅니다.

## 팔레트 수명 (메인 `PaletteController`)

1. `edge.hover` → 팔레트 레이아웃 계산(`computePaletteLayout`), 위치 계산(`placePalette`: 가장자리 바로 안쪽, 커서 중심, 작업 영역 안) → 헬퍼 `edge.setPaused(true)` → 렌더러가 그린 뒤 `showInactive()`
2. 50ms마다 커서가 **유지 영역**(팔레트 ∪ 트리거 지점, 18px 여유) 안인지 확인합니다. 밖에 있는 시간이 닫힘 지연을 넘으면 닫습니다. 드래그 중(`palette:interaction true`)에는 세지 않습니다.
3. 닫을 때 ghost를 숨기고 `edge.setPaused(false)` → 헬퍼는 그 가장자리를 `disarmed`로 두어, 커서가 벗어났다 돌아와야 다시 뜹니다.

팔레트 창은 `type: 'panel'`(non-activating NSPanel), `acceptFirstMouse: true`, 모든 Space·전체 화면 위에 표시합니다. 그래서 대상 앱의 포커스를 뺏지 않고, 첫 클릭부터 바로 셀이 선택됩니다.
